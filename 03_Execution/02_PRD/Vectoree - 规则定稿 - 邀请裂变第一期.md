## 1 目标与边界

**要做的：** 已激活用户（自己先 `link` 成功）用专属链接拉新用户。新用户成为**自己的默认组织 owner**，首次有效 `link` 且欢迎额度入账后，双方各得 $5 平台额度。

**不是：** 分佣、提现、拉同事进自己的组织、多级返利。

成功指标是**有效激活**（首次 `link` 且过现网发奖条件），不是注册数。

---

## 2 已锁定规则

1. 被邀请人 $5 **复用**现有欢迎额度，进其默认组织钱包，不再加码。
2. 邀请人另 $5，进其默认组织钱包；金额对称。
3. 每名邀请人最多 **10 次成功**，按成功次数计，不按发出去的链接人数计。
4. 邀请人自己必须先 `link` 成功，才能生成/复制专属链接。
5. 被邀请人没领到欢迎额度时，邀请人也不发。
6. 默认空项目算有效 `link`。
7. 不允许事后补填邀请码；关系在**被邀请人注册成功**时锁定。
8. 第一期面向全部用户。
9. 额度是组织钱包余额，靠 AI token / 网关 / 工具费消耗。不发现金。裂变规则和裂变产品页不写「未充值收回」。
10. 入账后额度 TTL：**30 天**（产品页文案）。邀请人那 $5 按此口径；被邀请人那 $5 走现网欢迎额度发奖器（见 §5）。
11. **7 天窗口**从被邀请人**注册成功**起算，不是邀请人的注册时间。超过 7 天才 `link`：被邀请人自己的 $5 仍发；邀请人那 $5 不发。
12. **两个入口：** 成员管理 = 拉同事；邀请好友 = 裂变。不混成一个按钮。
13. 已有 Vectoree 账号点专属链接：不绑定、不发奖；提示仅限新用户，并引导去自己的「邀请好友」。

---

## 3 主路径

1. 邀请人自己 `link` 成功后，系统自动生成**一人一条**长期专属链接（可复制）。未 `link` 时，「邀请好友」页只展示「先连接项目」，不给链接。
2. 被邀请人打开链接。
3. **未登录的新用户**完成注册（国内短信 OTP / 海外邮箱，见 §6）→ 锁定邀请关系，成为自己的默认组织 owner → **7 天从这一刻起算**。
4. 7 天内完成首次有效 `link`，且欢迎额度真正入账 → 被邀请人 $5 + 邀请人 $5（邀请人成功次数未满 10）。
5. 超过 7 天才 `link`，但过了现网发奖条件 → 只发被邀请人欢迎额度。
6. 7 天内 `link` 了但没过验证 / 同设备已领 / 组织已充值等 → 欢迎额度不入账，邀请人也不发。

点了链接一直没注册：关系没锁，7 天还没开始。

```
专属链接
  ├─ 未登录新用户 → 注册成功锁定 → 7天内有效 link 且欢迎额度入账
  │                    ├─ 邀请人未满 10 次 → 双方各 $5
  │                    └─ 邀请人已满 10 次 → 只发被邀请人欢迎额度
  ├─ 已有账号 / 已登录 → 不绑定，引导去自己的邀请好友
  └─ 邀请人点自己的链接 → 按已有账号处理
```

---

## 4 链接与入口

### 4.1 一人一条长期专属链接

- 首次自己 `link` 成功后自动生成，可复制。
- 不审批、不选角色、不能邮箱直加、不设「通过上限」。
- 不需要创建多条链接。
- 可「重置链接」：旧链失效。**已经用旧链注册、仍在 7 天窗口内的进行中关系，仍按原绑定结算**，避免重置洗记录。

### 4.2 满 10 次之后

- 专属链接仍可被新用户使用。
- 被邀请人照常注册、照常拿自己的欢迎 $5。
- 邀请人不再发第 11 笔。
- 进行中的人（已注册未 `link`）按完成先后占名额，先到先得。
- 产品页写：最多成功邀请 10 人。

### 4.3 入口位置

- **账号级**独立「邀请好友」页（侧栏或用户菜单），不进组织「成员管理」。
- 裂变关系是用户对用户，不是组织对组织。
- 成员管理继续只拉同事。
- 复用成员邀请「生成 / 复制」的交互壳；不复用 `oi_` token、join 路由、审批、默认角色、邮箱直加。

### 4.4 邀请人页状态

最少三态，第一期要能看见：

| 状态 | 含义 |
| - | - |
| 已注册未连接 | 7 天倒计时进行中 |
| 已发放 | 双方结算完成（或仅对方拿到欢迎额度且邀请人因满 10 / 对方未领到而不发时，须能区分，见下） |
| 已逾期 | 超过 7 天；对方仍可能拿自己的 $5，邀请人拿不到 |

「已发放」建议能看出：邀请人是否拿到自己的 $5（满 10、对方风控未入账时，对方可能有欢迎额度而邀请人没有）。

第一期**不做**站内信 / 邮件通知。

---

## 5 两笔 $5 怎么入账

| 谁 | 怎么发 | 怎么花 | 到期 |
| - | - | - | - |
| 被邀请人 | 复用现网欢迎额度（`InstallBonusService`） | 默认组织钱包，token / 网关 / 工具费 | 走现网欢迎额度行为。现网工程里有「到期未充值收回」。**第一期不改这套。** 裂变产品页不写这句。 |
| 邀请人 | 独立一笔记账，仅当对方欢迎额度真正入账，且本人成功次数 < 10，且在 7 天内 | 默认组织钱包，同样靠使用消耗 | 产品页写「入账后 30 天」。**不**套用「未充值收回」 |

同一对邀请关系只结算一次邀请人奖励。

---

## 6 短信与「账号已验证」

领奖条件从「邮箱已验证」升级为 **账号已验证**：邮箱验证 **或** 短信 OTP，二选一。不要强制短信用户再绑邮箱。

- 有邮箱时，仍拦截一次性邮箱。
- 同一条专属链接：国内站落地短信注册/登录，海外站落地邮箱。
- 邀请关系在**注册成功**时绑定，不绑渠道。
- 短信 OTP 成功 = 注册成功 = 锁定关系 = 视同已验证。
- 没过验证：自己拿不到 $5，邀请人也不拿。过了 7 天才验证并 `link`：自己的欢迎额度仍可发，邀请人不再发。

---

## 7 边界

| 情况 | 处理 |
| - | - |
| 已有账号点链接 | 不绑定、不发奖；提示仅限新用户；引导去自己的「邀请好友」 |
| 登录态点自己的链接 | 同上 |
| 多账号 + 同设备 | 现网 `device_hash`：被邀请人领不到欢迎额度，邀请人也不发 |
| 重置链接 | 旧链失效；已锁定的进行中关系继续结算 |
| 满 10 后新用户仍注册并 `link` | 只发被邀请人欢迎额度 |
| 组织拉同事 | 不是裂变；不发这套奖励 |

---

## 8 产品页必须写清

- 新用户成功连接项目后得 $5 额度；邀请人同时得 $5 额度。
- 每位邀请人最多成功邀请 10 人。
- 你需要先成功连接自己的项目，才能邀请。
- 对方注册后 7 天内完成连接，你才能拿到邀请奖励；逾期对方仍可得自己的 $5，你不再得。
- 链接只对新用户有效；不能事后补填邀请码。
- 额度打进组织钱包后 30 天内可用来跑 AI / 网关。
- 额度进入组织钱包，随模型 token 和工具调用扣减；不是现金、不能提现。
- 邀请同事进团队走成员管理，不走这条。

不写「未充值收回」。被邀请人 Billing 上若仍出现现网欢迎额度那句到期文案，那是欢迎额度页，不是裂变页。

---

## 9 第一期不做

多级返利、分佣提现、邮箱直加、审批加入、Waitlist、排行榜、按仓库质量结算、按真实扣费再发邀请人奖励、站内信/邮件通知、改现网欢迎额度的「到期未充值收回」。
