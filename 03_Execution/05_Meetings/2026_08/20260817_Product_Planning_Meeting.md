# 产研管理流程与 V1.0 发版规划会议

**会议日期**：2026-08-17  
**参会人**：佘总、PM  
**会议主题**：产研管理流程共识、研发协同机制确定与 V1.0 发版目标同步

---

## 1. 产研管理流程确认
经与佘总详细同步，双方达成共识：**后续全面采用当前搭建的基于飞书多维表格的产研管理体系**进行日常需求、版本与缺陷的管理和追踪。

## 2. 研发协同机制与发版节奏
为保障产研协作的透明度和交付效率，会议讨论并确定了以下日常机制：
- **每日站会**：正式确立每日站会同步流程，保障团队信息拉通与风险及时暴露。
- **需求评审**：建立定期进行需求评审的机制，确保开发进入前达成需求认知对齐。
- **发版节奏**：暂定为 **2 周一个迭代**。每个迭代开启前需召开正式的迭代会议。

## 3. 产品发布 Timeline 目标
- **2026 年 8 月底**：发布 V1.0（MVP 第一版）
- **2026 年 9 月底**：发布完善版本（V1.5+）

---

## 4. 8 月底 V1.0（第一版）核心发布范围
基于工程库中已梳理的正式上线清单（[launch-checklist.md](file:///Users/yuke/Documents/pm-workspace-vect/launch-checklist.md)），8 月底上线的 V1.0 将严格控制交付边界，优先打通核心商业闭环与基础开发者能力。具体包含以下功能范围：

### 4.1 核心交付能力
- **模型网关与调用**：支持模型网关 + API 密钥，保障 AI 模型基础调用通畅。
- **基础核心组件**：Auth（鉴权）、Database（数据库）、Storage（存储）。
- **用户账号与登录**：支持 Google 一键登录与邮箱验证码（OTP）登录。
- **组织钱包与计费**：上线组织钱包充值功能（PAYG 按量付费模式），并接通 Stripe 生产环境收款。
- **开发者工具**：发布 `@vectoree/cli` 原子命令工具（支持 `login` / `link` / `db` / `storage` / `ai` 等）与 Agent Skill 场景编排。

### 4.2 体验优化与克制展示
- **Landing Page 调整**：官网文案主推 Skill + CLI，并将定价策略明确调整为充值 PAYG（按量付费）模式。
- **未就绪功能隐藏**：V1.0 期间，前端入口将严格隐藏模板（Templates）、能力中心（Skills Hub）、自定义部署（Deployments）等未成熟模块，避免功能断层对用户体验造成影响。

### 4.3 运维与环境分离
- **测试与生产拆分**：正式拆分测试环境（`vectoree.net`）与生产环境（`vectoree.ai`），确保两套环境的数据、密钥与部署管线完全独立运行。
