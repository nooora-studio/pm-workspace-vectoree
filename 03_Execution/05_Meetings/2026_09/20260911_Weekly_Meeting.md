## 二、会上拍板的产品口径

### 1. Project 与本地目录必须 1:1

一个 Project 只能绑一个本地工程。四个人开发**同一个**项目可以都 link；做四个不同项目就建四个 Project。

- Dashboard 用量、数据都是 **Project 维度**。一个 Project 绑多个本地目录，数据会混在一起。
- CLI：link 时校验目录名，不一致**直接拒绝**。只有 owner 能换绑。
- CLI 要把本地目录名上报到平台，Connected 卡片左侧展示目录名。

### 2. onboarding 怎么引导、怎么发 $5

- **只引导第一个人**（default 组织 / default project / project owner）。
- 项目一旦被 link 过，后续成员**不弹强引导模态**，走右上角 Connect 复制粘贴，或看 Docs。
- 奖励只发给 owner。以下情况连接成功但不发奖励：**组织已充值 / 邮箱未验证 / 设备 ID 重复**。
- 对用户**只说「项目连接成功」**，不要解释为什么没奖励（解释了人家会觉得亏了 5 块）。

### 3. Connected 状态

现在是纯 CLI 调接口，没有心跳，不做真实 active 判定。**连接过就展示**，没连过不展示。文案用 Connected（已连接），不要叫 active。

中途退出：onboarding 收起到左下角，记下 progress，可以回来继续。校验失败可以重试。

### 4. 国内版

- **不做邀请制白名单**，直接开放注册。
- 产研只需加 **手机号短信登录**。
- 微信 / 支付宝已打开，钱收到香港公司，**支付不用改代码**。
- 域名、备案、算法备案、大模型登记等资质由老佘走。

### 5. 收费怎么对外说

- 现在收费的只有 **Model + Tool Hub**。
- Database / Auth / Storage **目前免费、没有上限**，增长侧可以当卖点宣传。
- 后面会做订阅 / 配额（挂组织还是项目，待定）。
- **部署一定收费**（成本高），方案随技术方案再定。

### 6. 先 ship，工具往后放

素材生成、视频克隆这类纯工具获客更快，但和「帮用户把 agent 做出来再卖」是两条线。**先把 ship 链路做完**，工具类往后放。
