## 二、会上拍板的口径

### 1. 邀请裂变 ≠ 分佣

拆成两套，不要混：

- **邀请**：被邀请人成功 **link** 后双方各得 **$5 平台额度**（必须花在 Vectoree），邀请上限 **10 人**。不做提现。
- **分佣 / 渠道商**：以后要赚钱再走另一套体系，系统要单独做现金账户和打款，这期不做。

现金拉来的人容易薅完就走；额度留在平台里。话术可以写成「抵网关 / 数据库费用」，但账上仍是额度。

Waitlist 已经 public，不必做。内部其他项目组以后要用邀请，先做一版自己能用的。

### 2. 国内版需求只留两条

需求池里拆太细的（自定义域名、合规检查表、封闭版先行、红线清单当独立任务等）**删掉或并进大需求**。研发只认：

1. **短信登录**（海外也可以加；国内环境只开短信）  
2. **国内环境搭建与部署**（腾讯云再布一套；云资源可先开，付款跟流程）

境内外隔离（域名 / DB / 密钥 / 账单 / 日志）必须做，但不必再拆成一堆排期项。Cloudflare 没有国内节点，国内用腾讯云自己的防护即可。支付国内已有微信等能力，按环境变量切，代码不用大改。

国庆前发一版国内：**够呛，但路径短**——改短信 + 创建国内资源。界面已有多语言，不是阻塞。

### 3. 部署：先出方案，不在 S1 开发

则东用 AI 对标 Vercel 看了两条路线，**都不要直接用**；纯自研周期长。目前多半是 Docker，早期用户少够用，规模化后这套会扛不住，还要算给用户怎么收费。

**则东出自己的判断和方案，中秋后再评审。** 控制台最小闭环 = 内部租户一键部署出预览 URL。开源能拿来的先拿来，不必一次做很大。

### 4. 环境与节奏

- 测试环境今晚收口，验收走测试机，生产少动。  
- 则东建议后续再补偏预发的稳定环境，以及产品单独的 Demo 环境（少登录、少连库，方便跟研发实现对比）。流程再跟琼冰打磨，今天不拍板加环境。  
- 小任务（0.5 点、界面、小 bug）当天合；连库 / 接口调不通的按估点对齐，不要假一天。  
- 写代码前先落 md，再基于 md 出 plan。允许犯错，**组织效率是竞争力**。

### 5. Gallery / SEO 别抢部署之前

首页先加 QA（琼冰下周可上）。Model、Template 页面对收录更有用，但要做模块，排在国内版和部署之后。Gallery 点进去要能真实用（登录 / 功能 / 支付），依赖部署能力；没有部署就先当「内测作品」叙事，不要假装海量可运行 Agent。皮子站、热词独立站、小工具 cover 词先记待办，种子用户之后再做。高价值 Blog 仍是 SEO 正道。

## 三、增长与商务

### 社区 / 获客

- Twitter/X：从发帖改成**建联 + 留言**。官方号会撞每日私信上限；高评论帖难被看见。改从黑客松提交页拿提交人名字，去社交账号检索（重名少就能找到）。参赛以印度人居多。
- Discord：来过一个日本人（IT，说合作，反馈 `seems like good`，更像找 remote）；一个女装试衣早期站点的人，来了就走。以后引导要问**缺什么、做到哪一步**。像找工作 / 发广告的不少。
- 转化：大约 100 个 visit 才 1～2 个注册。要漏斗 **visit → click（如 Get Started）→ register**，先分清「没点开 / 点了没注册」。渠道来源后置。石瑜去看 admin、自己把产品用一遍。
- Discord 服务器徽章要 3 个 Nitro boost，大约 $9.9，小额可付。
- Backlink 在加；广告账号只做到 prepare、未开通。
- 本周最大变化：时间压到**私人邀约**。

### 邮件冷启动（老佘侧）

手里有约 **200 万**开发者邮箱（朋友的发送工具库，不是现场爬的）。**不能用主域名群发**，要备用 `.com` 域名，慢慢发、养号。**不要用二级域名**（会污染主域，Google / Spamhaus 风险高）。也不能一天十万封。石瑜以前的做法是预热后再放量。有了这份名单，**$2000 的外包反馈合同不急**；合同仍可先走，付款再说，议价问曾总。
