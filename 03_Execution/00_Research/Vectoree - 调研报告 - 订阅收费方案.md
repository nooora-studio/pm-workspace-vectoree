## 4 调研结论

1. **这六家里没有人用纯月费包住模型或工具。** OpenRouter、Monid 连月费都没有。InsForge 的 $25 明确把模型网关写成按用量另计。把 token 或 Tool Hub 包进月费，市场上没有可对标的价，也盖不住单价跨度。

2. **Agent 后端的心理价已经钉在 $25。** InsForge Pro 和 Supabase Pro 同为 $25（InsForge 年付 $20）。配额表几乎同一套：5 万 / 10 万 MAU、500 MB / 8 GB 盘、5 GB / 250 GB 带宽、1 GB / 100 GB 文件、超出 $0.00325、$0.125、$0.09、$0.021。InsForge 是在这张表上加了站点构建和自定义计算，不是另起一套价。Vectoree 以后若卖月费，用户会拿 $25 来比。

3. **算力不在月费里。** 两家都写明 $10 credit 只够 1 个 Micro，第二台加 $10，Large 一台就把账单从 $25 抬到 $95。部署若上线，订阅可以含「1 条生产地址 + 一份构建额度」，常驻规格必须另计。按「项目大小」收一笔，对不上这张已经公开的账单。

4. **模型平台费收在充值，不收在 token。** OpenRouter 把这句话写在定价 FAQ 里：各档推理都是供应商标价；Standard 买额度加 5.5%，Business 加 8%。Business 更贵，是因为区域内路由、1,000 个工作区，不是因为模型打折。失败的模型调用不扣 token。

5. **工具调用用同一个预付余额按次扣。** Monid 的对外句子是不做订阅。Vectoree Tool Hub 已经是这个结构。工具不适合再做一层月费。

6. **免费档的转化杠杆是「不用就停」，不是赠送 token。** InsForge 和 Supabase 都是一周无活动暂停。Vercel Hobby 是超额即停、不能加购。OpenRouter 免费模型 50 次/天。四家都不用「每月送 100 万 token」当免费档。

7. **Clerk 的月费和账单不是一回事。** $25 含 5 万 MRU 和 1 条 SSO。第 2 条 SSO $75，多一个组织 $1，多一个卫星域 $10。MRU 超出单价（$0.02）约是 Supabase MAU 超出单价（$0.00325）的 6 倍。这种「低月费 + 刚需按个加价」能把 $25 的账单打到数百美元。

8. **Vercel 说明部署该计量，也说明维度不能铺太开。** 构建已经细到 $0.007 / 分钟。同时一张账单上有传输、CPU、调用、Blob、WAF。他们用 $20 credit 和默认 $200 预算来收口。Vectoree 若做部署，计量项保持少，并给余额或预算上限。

9. **花费必须能在扣光前看见。** Supabase Pro 默认花费上限。OpenRouter 余额用完即停，并且 Key 可以单独设上限。Vercel 到预算可暂停。模型网关和工具按次若没有上限，一张失控账单会先于任何月费出现。

10. **InsForge 已经占住「$25 的 Agent 后端」。** 配额、暂停、算力 credit 都和 Supabase 对齐，另外把站点构建（免费 600 分钟，Pro 不限）和模型按量放进同一产品。Vectoree 现网还没有按项目计量，也没有暂停。在计量做出来之前卖一个月费档，卖的是 InsForge 价目上的空位。

## 5 由此得到的 Vectoree 方案

对应关系写在每条后面。

### 5.1 现在就保持的

| 项 | 做法 | 依据 |
| - | - | - |
| 月费 | 不卖 | 结论 10：没有计量和暂停，月费没有东西可卖 |
| 模型 | 组织钱包，按 token / 按秒 | 结论 1、4 |
| Tool Hub | 同一钱包，按目录标价每次扣，含 Try | 结论 5。失败但运行时已执行的调用，文档站已规定仍扣标价 |
| Templates | 不收费 | 现网是本地克隆，不是 InsForge 那种托管站点 |
| Auth、数据库、存储 | 不对用户出账 | 还没有按项目的计量。内部要有上限，因为结论 6、9：共享资源不设停，成本是敞口 |
| 对外句子 | 充值、按模型和工具扣、无月费 | 与 OpenRouter Standard、Monid 同结构 |

平台费建议只放在充值：模型按上游标价扣钱包，买额度时加一笔手续费。锚点用 OpenRouter Standard 的 **5.5%**。不在 token 上再加一层 markup。各档如果以后出现，手续费保持同一个数；不要学 OpenRouter 把 Business 收到 8%（结论 4：那一档贵的是功能，我们还没有对应功能）。

### 5.2 计量做完之后的月费

触发条件：磁盘、存储、出口能按项目入账，并且免费项目可以暂停或硬停。在这之前不开这一档。

建议档位对 InsForge / Supabase，不另起价：

| | Free $0 | Pro $25 / 组织 / 月 | Enterprise |
| - | - | - | - |
| 对照 | 两家的 Free | 两家的 Pro | 两家的销售档 |
| 项目 | 少量，建议先按 2 个封顶（Supabase Free） | 第 1 个最小规格含在月费 | 合同 |
| 不用就停 | 要有。一周无活动暂停，或配额到顶即停 | 不暂停 | 不暂停 |
| 数据库盘 | 500 MB | 8 GB，超出 $0.125 / GB | 定制 |
| 出口 | 5 GB | 250 GB，超出 $0.09 / GB | 定制 |
| 文件 | 1 GB | 100 GB，超出 $0.021 / GB | 定制 |
| 终用户 | 观察线，先不对外承诺 5 万 | 若开始计量：10 万内含，超出 $0.00325 / MAU | 定制 |
| 模型、Tool Hub | 仍走钱包，月费不含 | 仍走钱包 | 仍走钱包 |
| 自定义域名 | 无 | **含在 $25，不按个数加价** | 含 |
| SSO | 无 | 无 | 含，不按连接 $75 |

$0.125、$0.09、$0.021、$0.00325 是两家已经公开的超额价，用来避免低于行业成本价去抢。Vectoree 若自己的上游更便宜或更贵，改单价，不改「月费含配额、超出按量」这句结构。

$25 不按席位卖。Vercel 的 $20 是开发者席位，买的是谁能部署。Vectoree 现网不按人头协作计费。等成员和审计真成为购买理由，再加席位，不把 $25 先写成 $49/人。

自定义域名放进 Pro，不学 Supabase 的 $10/域名、也不学 Clerk 的 $10/卫星域（结论 7）。

### 5.3 部署上线时加的计量

Deploy 仍未上线。上线后按结论 3 和 8 加行，不改 5.2 的月费逻辑。

| 项 | 放哪 | 对照 |
| - | - | - |
| 生产地址条数 | Free 1 条；Pro 更多。这是功能，不按流量抽成 | InsForge 把「有站点」放进计划 |
| 构建分钟 | Free 设上限。InsForge 免费档是 600 分钟，可作上限参考，不照抄成承诺。超出按分钟进钱包，单价参考 Vercel 基础机器 $0.007/分钟，用自己的构建成本改 | 结论 8 |
| 常驻 / 容器 | 按规格 × 小时进钱包，不进 $25。$25 最多含一份相当于 1 个最小实例的额度 | InsForge：$10 credit 只抵 1 个 Micro；Custom Compute 不吃这 $10 |
| 站点出口、产物体积 | 并进 5.2 的出口和存储，不新造「项目大小」 | 结论 3 |
| Pro「构建不限」 | 不采用 | InsForge Pro 写了不限站点构建。在知道单次构建成本之前，这句会变成敞口 |

### 5.4 明确不做

- 月费包无限模型或无限 Tool Hub（结论 1、5）
- 充值手续费和 token markup 叠收（结论 4）
- SSO、组织、域名按个数加价（结论 7）
- 在计量和暂停落地前上架 $25 档（结论 10）
- 本期为 Templates 或终用户 Payments 定价。Payments 仍是 Coming soon；模板交易市场现网不存在

## 6 采用前要拍板的三个数

方案结构按第 4 节可以先定。下面三个数还要用内部成本确认。

| # | 要定的 | 建议 | 不采纳 |
| - | - | - | - |
| 1 | 充值手续费 | 5.5%，各档相同；token 按上游标价 | 手续费再加 markup；或学 Business 收到 8% |
