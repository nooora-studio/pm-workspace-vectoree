口径：One console. Four blocks. —— 模型网关 / Auth / Database / Storage + 组织钱包 PAYG

一、产品模块思维导图（当前已上线 · 四块积木）

四大积木（上线交付） 计费底座（钱包 PAYG） 开发者入口（Skill + CLI） 操作路径

口径提醒：六块积木（模型/模板/技能中心/认证/支付/数据）是战略愿景版，来自官网营销落地页。当前已上线只交付四块：模型网关、Auth、Database、Storage；模板、能力中心、部署在上线时已从侧栏与落地页隐藏，未交付。定价为 PAYG 钱包、无月费，不是愿景版里的 Free/Pro/Team 订阅档。

二、操作路径

D1 用户 / 租户路径（人在控制台）

01
注册 / 登录
Google 一键 / 邮箱验证码(OTP)
→
02
建组织 · 项目
拿项目 API Key
→
03
Model Plaza 选模型
Playground 试跑 · 生成 Key
→
04
配 Auth
登录方式给 app 用户用
→
05
建 Database / Storage
Dashboard 建表 · 建 Bucket
→
06
钱包充值 → 调网关
Stripe 充值 · 按用量扣费

硬约束：空钱包不能调网关。Auth / Database / Storage 上线内含（共享实例配额），不单独出账。

D2 开发者 / Coding Agent 路径（Skill + CLI · OpenAI 兼容）

01
装 Agent Skill
npx skills add VectoreeAI/vectoree-skills
→
02
CLI 登录绑定
npx @vectoree/cli login(PKCE) → link
→
03
调模型网关
vectoree ai models list → ai chat / snippet
→
04
用 DB / Storage
vectoree db * / vectoree storage *
→
05
CI / 无浏览器直跑
VECTOREE_API_KEY 即可（OpenAI 兼容 endpoint）

说明：开发者主路径是 Skill（场景编排）+ CLI（原子命令），不是 @vectoree/sdk。SDK 是应用运行时，上线不交付、列为后置。
