运营模型录入总表 · 模板

由「单模型上架向导」录入字段 1:1 推导，供运营同学批量维护、再经批量导入落库。区域为标准受控词表（43 个，见文末）。

使用方式：① 主表每行一个模型（核心字段）；② 区域价、限时折扣是「一个模型对多条」的明细，单独成表（Sheet 2 / Sheet 3）；③ 三张 CSV 已生成在同目录，可直接发运营填写，再走 v2 表单「批量导入」标签页映射落库。

字段说明
· 对外 slug：沿用运营表 Base_slug（厂商/型号原名，如 deepseek/deepseek-v4-flash），斜杠前是命名习惯不是渠道；暂不强加 vectoree/ 前缀。
· 渠道决策：调供应商＝用「主渠道」列；走openrouter＝主渠道填 openrouter 默认聚合。
· 主/备上游模型ID：Layer 2，按渠道类型取（OpenRouter 远程下拉 / 直连厂 from provider.csv / Azure·Custom 手填）；主备的上游ID 不同。
· 计费模式：10 选 1（Token文本 / Token Embedding / Token视觉 / 图像生成 / 音频TTS / 音频转写 / Token音频 / 视频生成 / 固定按次 / 透传上游成本）。
· 成本折扣 / 售价折扣：对应 openrouter.csv「供应商折扣 / 我们设置的折扣」；成本＝刊例×成本折扣，售价＝刊例×售价折扣，利差＝售价−成本。
· 输入/输出/缓存价：仅 Token 模态填，来自 provider.csv 的 Input/Output/Cached。
· 刊例价来源/同步地址：若该刊例价由定时抓取脚本维护，填同步地址或标注「定时任务维护」。

Sheet 2 · 区域价明细（每行 模型 × 区域）

一个模型可挂多区域价。区域必须从标准词表下拉选择（见文末 43 个），不可手填。无此表行＝全局统一价。

Sheet 3 · 限时折扣明细（每行 模型 × 折扣活动）

限时折扣为独立生命周期事件（待生效→进行中→已结束），可多层叠加。生效止必填，否则批量预检拦截（对应 update.csv wan3.0「时间待定」）。
