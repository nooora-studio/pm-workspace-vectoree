What lives here

This is the maintainable 1:1 prototype for Vectoree. It mirrors the production product shell — topbar, sidebar, content grid, cards — extracted from the live CSS plus calibrated against the dashboard / admin screenshots under 01_Product/_Assets/Screenshots/. Use this demo to ship new requirements: edit any HTML file in place, the shared shell lives in _Assets/tokens.css + _Assets/layout.css.
